## Доработка сервера

1) Произведен рефакторинг сервера, так как для http предпочтительнее байтовые потоки для бОльшего контроля на низком
   уровне;
2) Устраняем уязвимость входящих http-запросов ограничением по памяти (4 кб);
3) Добавлен приватный метод badRequest, который возвращает массив байт для отправки сообщений клиентам в случае
   некорректного запроса на сервер;
4) Метод indexOf для получения кусочка байтового массива, который будет содержать необходимую информацию, такую как
   request line или headers;

## Доработка класса Request

1) Добавлено приватное поле для хранения заголовков Map<String, List<String>> headers и соответствующи сеттер;
2) Добавлено приватное поле для хранениея параметров запроса Map<String, String> queryParams;

## Согласно требований задания:

1) В точке входа программу, добавлен handler, который принимает http запрос:/messages как с параметрами, так и без.

   отправляем список параметров в ответе клиенту. На данном этапе потренеровался и отправил параметры через URL.
